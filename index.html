气球打字

带字母的气球从天上飘下来，按对应的键把它打掉——
打对了会飞出一只小鸟把气球啄破。
漏掉的气球会砸在地上留下一个坑，坑连成一片， 地面就塌一块；塌够几列这一轮就结束（要几列看难度档）。

玩法说明

键盘：只认字母和数字键，大小写都行。
请把输入法切到英文——中文输入法激活时浏览器收不到字母键。

键位模式：只出当前键位组里的键（如基准键·左手只有 A S D F G）， 按键盘区域一组一组练，手指击完回到基准行。
字母模式：气球上是一个字母，按对应键即击破。
单词模式：连续输入完整拼写才击破，中途打错会清空输入。
汉字模式：输入气球上汉字的完整拼音（全拼，ü 打 v）。

按对键 → 侧栏记录下这一次的真实反应时间，不做任何美化。
按错键 → 只计入正确率，不会直接判负。
真正决定生死的是地面：漏掉的球会砸坑，塌够列数就结束。

键盘输入：A–Z / 0–9（大小写均可） 音效：待启用

关于这个项目

  • 在线试玩：justa-cai.github.io/typing-balloon
    源码仓库：github.com/justa-cai/typing-balloon
  • 复刻对象是小霸王「中英文电脑学习卡」内置的《打字游戏》（SB-926 等机型标配）， 不是独立发售的游戏，也没有独立 ROM。哪些细节有确证、哪些是推测， 逐条记在仓库的 specs/prd.md 里。
  • 像素风是认真的：逻辑分辨率固定 256×240（FC 原生），显示只取整数倍， 字母用五乘七点阵字模逐像素画，汉字用本机字体现场二值化成点阵块， 所有图形走 fillRect、不用 ctx.arc（会抗锯齿）。
  • 音效现场合成：方波 + 三角波 + 噪声，参数写在 js/audio.js 的一张表里， 一个音频文件都没有。
  • 零依赖、零下载：无构建步骤、无 CDN、无图片字体音频资源， 整个游戏就是几个文本文件，可直接托管在 GitHub Pages。
  • 难度沿用原版的 0～9 十档，四个旋钮（下落秒数 / 生成间隔 / 同屏上限 / 塌陷列数） 全部显式写在 js/difficulty.js，测试时可以在 console 里直接读数核对。
  • 许可为 MIT（全自研，无第三方代码与资源）。调研来源与自研声明见 NOTICE.md。
